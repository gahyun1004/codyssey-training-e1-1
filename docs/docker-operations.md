# Docker 운영 실습

## 설치 및 연결 점검

```bash
docker --version
docker version
docker info
docker run --rm hello-world
```

## 이미지와 컨테이너

```bash
docker images
docker ps
docker ps -a
docker logs <container_name>
docker stats --no-stream
```
